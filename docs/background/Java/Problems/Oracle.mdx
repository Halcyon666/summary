### 报错处理二

```

```

[处理方案](https://dbatricksworld.com/ora-00205-error-in-identifying-control-file-check-alert-log-for-more-info/)

具体操作步骤：

* 使用命令dbca创建数据库jc中，去/usr/oracle/app中执行如下命令：即可拿到control_files路径。
  `find . -name control0*`
* 在SQL>窗口中执行如下命令，看control_files的路径如查找到的是否一致

```
show parameter control_files
alter system set control_files='/usr/oracle/app/oradata/jc/control01.ctl'  scope=spfile;
alter system set control_files='/usr/oracle/app/flash_recovery_area/jc/control02.ctl'  scope=spfile;
```

## 使用MybatisPlusInterceptor + DynamicTableNameInnerInterceptor实现多租户

这个可以实现单schema动态名schema，但是sequence的schema前缀是没有的
```java
@Configuration
public class MybatisPlusConfig {

    // schema白名单，防止非法拼接
    private static final Set<String> SCHEMA_WHITELIST = Set.of("SCHEMA_A", "SCHEMA_B");

    // 需要动态切schema的表（其余表原样执行，不做任何改写）
    private static final Set<String> MANAGED_TABLES = Set.of("orders", "order_items");

    @Bean
    public MybatisPlusInterceptor mybatisPlusInterceptor() {
        MybatisPlusInterceptor interceptor = new MybatisPlusInterceptor();

        // 如果有分页插件，必须先加分页，再加动态表名，顺序影响处理链
        interceptor.addInnerInterceptor(new PaginationInnerInterceptor(DbType.ORACLE));

        DynamicTableNameInnerInterceptor dynamicTableNameInterceptor =
            new DynamicTableNameInnerInterceptor();

        dynamicTableNameInterceptor.setTableNameHandler((sql, tableName) -> {
            String schema = SchemaContextHolder.getSchema();

            // 未设置schema，原样返回，不介入（走数据源默认schema）
            if (schema == null || schema.isEmpty()) {
                return tableName;
            }
            if (!SCHEMA_WHITELIST.contains(schema)) {
                throw new IllegalArgumentException("非法schema: " + schema);
            }
            if (!MANAGED_TABLES.contains(tableName.toLowerCase())) {
                return tableName; // 非受管表不改写
            }
            return schema + "." + tableName;
        });

        interceptor.addInnerInterceptor(dynamicTableNameInterceptor);
        return interceptor;
    }
}
```

补充sequence schema前缀方案，使用`${schema}`。
或者可以使用这种方式静态添加schema，（⚠️一个工程引入多个数据源，只会有一份keygenerators。）

```java
@Component
public class SchemaAwareOracleKeyGenerator implements IKeyGenerator {

    @Override
    public String executeSql(String incrementerName) {
        String schema = SchemaContextHolder.getSchema();
        if (schema == null || !SCHEMA_WHITELIST.contains(schema)) {
            throw new IllegalArgumentException("取序列时非法schema: " + schema);
        }
        return "SELECT " + schema + "." + incrementerName + ".NEXTVAL FROM DUAL";
    }

    @Override
    public DbType dbType() {
        return DbType.ORACLE;
    }
}
```
